# Angular todo example

This project uses Angular CLI and the `withClientStore` helper from
`client-web-storage`.

1. Start the shared API as described in the [repository README](../README.md).
2. Run `npm ci` in this folder.
3. Run `npm start` and open `http://localhost:4200`.

Run `npm run build` to check the Angular templates and build the browser
bundle into `dist/angular2/browser`.
